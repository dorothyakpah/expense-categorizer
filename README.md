Expense Categorizer

A beginner Python project that automatically categorizes expenses, stores financial records, and calculates total spending.

Project Overview

The Expense Categorizer is a Python application designed to simplify basic expense tracking. It uses predefined rules to identify expense categories based on descriptions and stores expense information in Python data structures.

This project is being developed as part of my practical journey in Python development and automation.

Features

- Automatic expense categorization.
- Expense storage using Python dictionaries.
- Management of multiple expenses using lists.
- Automatic expense record creation.
- Calculation of total expenses.
- Rule-based text matching.

Technologies Used

Expense Categories

The current categorization rules cover:

- Groceries
- Entertainment

- Other

Concepts Applied

- Variables and data types

- Conditional statements

- List comprehensions

How It Works

1. An expense description is provided.
2. The program identifies its category using predefined rules.
3. An expense record is created.
4. The record is added to an expense list.
5. The program calculates the total amount spent.
